# 2088 文档 → 元数据 采用 QML 重构

## What

将「文档 → 元数据」（Document → Metadata）对话框由旧 `tm-widget` +
`dialogue-window` 迁移为 QML 弹窗 `DocumentMetadata.qml`，复用 `DialogShell` /
`DialogButtons` / `Theme` 原子板块。三个文本输入字段（Title / Author / Subject）
改为一次性提交（OK 时写回），按钮仅保留 Reset / OK（按用户要求不设 Cancel）。

## Why

复用 QML 对话框体系（`DialogShell` 外壳 + 主题单例 + 原子板块），与已迁移的
RetinaSettings / FormDialog / Preferences 保持一致的视觉与交互风格。原对话框为
live 每键写回且无 Cancel 撤销，改为一次性提交后语义更清晰：OK 落定、Reset 恢复
默认、关窗丢弃改动。

## How

1. **QML 正文**：新增 `src/Plugins/Qt/qml/DocumentMetadata.qml`，根用 `DialogShell`，
   `import "atoms"` 取 `DialogButtons` / `Theme`。字段通过 `Repeater` 渲染，每个字段
   为 label + `TextInput`（单行文本，`selectByMouse`，失焦/回车即写本地 values）。
   两按钮（OK / Reset），OK 走 `closeBridge.submit`、Reset 走 `closeBridge.choose(2)`。
2. **登记**：`qml/qmldir` 加 `DocumentMetadata 1.0 DocumentMetadata.qml`；
   `moganqml.qrc` 加 `<file>qml/DocumentMetadata.qml</file>`。
3. **C++ glue**：在 `QTMQmlDialog.cpp` 加 `cpp_document_metadata_dialog(tree fields)`，
   走 `run_qml_dialog`（exec 阻塞模态，元数据无需 live 重绘）。复用
   `field_tree_to_qml` 解析字段树（text 类型，options 为空串占位）。exec 退出码：
   `Accepted`(1)=OK → 返回 `(tuple (tuple key value)...)`；`2`=Reset → 返回
   `(tuple "reset")`；其余=关窗 → 返回空 `tuple`。测试钩子
   `MOGAN_TEST_DOCUMENT_METADATA=ok|cancel|reset`。
4. **glue 注册**：`src/Scheme/L5/glue_qt.lua` 加 `cpp-document-metadata-dialog`；
   `TeXmacs/progs/prog/glue-symbols.scm` 加符号。
5. **Scheme facade**：重写 `document-widgets.scm` 的 `open-document-metadata-window`，
   构建字段树（text 类型，三个字段 global-title / global-author / global-subject）。
   Scheme 侧处理 Reset 循环：收到 `(tuple "reset")` 时调 `initial-default` 重置三个
   变量后重建字段树重调。移除旧 `document-metadata-editor` tm-widget；
   `open-document-metadata` 直接走 QML 弹窗（移除 side-tools 分支）。
6. **偏好键**：在 `pref-keys.scm` 补 `pref-global-title` / `-author` / `-subject` 三个
   `define-public`，字段表构造统一引用。
7. **加载测试**：`tests/Plugins/Qt/qml_load_test.cpp` 加 `test_document_metadata_loads`，
   注入 `metadataFields` + `dialogButtons` 桩，断言 `status()==Ready`。
8. **清理 side-tools**：移除 `document-tools.scm` 中 `document-metadata-tool`（已无
   `document-metadata-editor` 可复用）。

### 字段树格式

复用 form 引擎协议（`field_tree_to_qml` 透传），text 字段用空串占位 options：

```
(form
  (text <label> <key> "" <value>))   ; value 为字符串
```

### 按钮返回值映射

| 按钮 | QML 调用 | exec 退出码 | C++ 返回 tree |
|------|---------|------------|--------------|
| OK | `closeBridge.submit(values)` | `Accepted`(1) | `(tuple (tuple k v)...)` |
| Reset | `closeBridge.choose(2)` | `2` | `(tuple "reset")` |
| 关窗 | — | `0`/`-1` | 空 `tuple` |

1. 启动 MoganSTEM，打开 `TeXmacs/tests/tmu/2088.tmu`（文档预置 Title /
   Author / Subject 元数据）。
2. 菜单 文档 → 元数据（Document → Metadata），应弹出 QML 对话框
   （`DialogShell` 外壳，圆角透明背景）。
3. 三个文本输入框应分别显示：
   - Title: \P2088: 文档元数据 QML 重构测试\R
   - Author: \PMogan Tester\R
   - Subject: \PQML refactoring\R
4. 修改任一字段，点 \PReset\R：三个字段恢复系统默认值（Title 默认回退到
   文件名 \P2088\R；Author / Subject 默认为空），弹窗不关闭。
5. 点窗口关闭按钮（\PX\R）：放弃改动；重新打开弹窗，字段显示原值。
6. 修改字段后点 \POK\R：写回 `global-title` / `global-author` /
   `global-subject` init 环境变量。重新打开弹窗，字段显示新值。
