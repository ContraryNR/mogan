# 2087 视图 → 高分屏设置 采用 QML 重构

## What

将「视图 → 高分屏设置」（macOS 为「Retina settings」）对话框由旧 `tm-widget` +
`dialogue-window` 迁移为 QML 弹窗 `RetinaSettings.qml`，复用 `DialogShell` /
`Toggle` / `EnumCombo` / `DialogButtons` 原子板块。

## Why

复用 QML 对话框体系（`DialogShell` 外壳 + 主题单例 + 原子板块），与已迁移的
FormDialog / FontSelector / ParagraphFormat / Preferences 保持一致的视觉与交互风格。

## How

1. **QML 正文**：新增 `src/Plugins/Qt/qml/RetinaSettings.qml`，根用 `DialogShell`，
   `import "atoms"` 取 `Toggle` / `EnumCombo` / `DialogButtons` / `Theme`。字段通过
   `Repeater` 按 `type` 分发：`"toggle"` → `Toggle`（value "on"/"off" ↔ bool）、
   `"enum"` → `EnumCombo`。三按钮（OK / Reset / Cancel），OK 走 `closeBridge.submit`、
   Reset 走 `closeBridge.choose(2)`、Cancel 走 `closeBridge.cancel()`。
2. **登记**：`qml/qmldir` 加 `RetinaSettings 1.0 RetinaSettings.qml`；`moganqml.qrc`
   加 `<file>qml/RetinaSettings.qml</file>`。
3. **C++ glue**：在 `QTMQmlDialog.cpp` 加 `cpp_retina_settings_dialog(tree fields)`，
   走 `run_qml_dialog`（exec 阻塞模态，高分屏设置无需 live 重绘）。复用
   `field_tree_to_qml` 解析字段树。exec 退出码：`Accepted`(1)=OK → 返回
   `(tuple (tuple key value)...)`；`2`=Reset → 返回 `(tuple "reset")`；其余=Cancel →
   返回空 `tuple`。测试钩子 `MOGAN_TEST_RETINA_SETTINGS=ok|cancel|reset`。
4. **glue 注册**：`src/Scheme/L5/glue_qt.lua` 加 `cpp-retina-settings-dialog`；
   `TeXmacs/progs/prog/glue-symbols.scm` 加符号。
5. **Scheme facade**：重写 `view-widgets.scm` 的 `open-retina-settings-window`，
   构建平台分支字段树（macOS: retina-factor + 条件 retina-scale；非 macOS:
   retina-zoom + retina-icons + 条件 retina-scale）。Scheme 侧处理 Reset 循环：
   收到 `(tuple "reset")` 时调 `reset-retina-preferences` 后重建字段树重调。
   移除 `open-retina-settings` 的 side-tools 分支，直接走 QML 弹窗。
6. **偏好键**：在 `pref-keys.scm` 补 `pref-retina-factor` / `-zoom` / `-icons` /
   `-scale` 四个 `define-public`，字段表构造统一引用。
7. **加载测试**：`tests/Plugins/Qt/qml_load_test.cpp` 加 `test_retina_settings_loads`，
   注入 `retinaFields` + `dialogButtons` 桩，断言 `status()==Ready`。

### 字段树格式

复用 form 引擎协议（`field_tree_to_qml` 透传），toggle 字段用空串占位 options：

```
(form
  (toggle <label> <key> "" <value>)       ; value = "on" / "off"
  (enum   <label> <key> (<opt>...) <value>)) ; value = "1" / "1.2" / ...
```

### 按钮返回值映射

| 按钮 | QML 调用 | exec 退出码 | C++ 返回 tree |
|------|---------|------------|--------------|
| OK | `closeBridge.submit(values)` | `Accepted`(1) | `(tuple (tuple k v)...)` |
| Reset | `closeBridge.choose(2)` | `2` | `(tuple "reset")` |
| Cancel | `closeBridge.cancel()` | `Rejected`(-1) | 空 `tuple` |

### 手动验证
1. 启动 MoganSTEM，打开 `TeXmacs/tests/tmu/2087.tmu`。
2. 菜单 视图 → 高分屏设置（macOS 为 Retina settings），应弹出 QML 对话框
   （`DialogShell` 外壳，圆角透明背景）。
3. macOS：弹窗显示 \PUse retina fonts:\R 开关；非 macOS：显示
   \PDouble the zoom factor for TeXmacs documents:\R 与 \PUse high resolution
   icons:\R 两个开关。
4. 当 \Pgui theme\R 偏好非空时，额外显示 \PScale graphical interface:\R
   （macOS）或 \PScale of the graphical user interface:\R（非 macOS）枚举字段。
5. 切换开关或选枚举项，点 \PReset\R：字段回到系统默认值（弹窗内立即刷新，
   不关闭）。
6. 点 \PCancel\R 或关窗：放弃改动；重新打开弹窗，字段保持原值。
7. 点 \POK\R：写回偏好并弹出重启提示（`cpp-confirm-restart`）。
